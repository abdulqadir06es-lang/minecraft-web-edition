# 🎮 MineCraft Web Edition

Ek 3D Minecraft-style sandbox game jo bilkul browser mein chalti hai — bina install kiye!

**▶️ Live Kheliye:** https://abdulqadir06es-lang.github.io/minecraft-web-edition/

## ✨ Features
- 🌍 3D World — pahariyan, darakht, terrain
- 🧱 30+ Blocks (Ice, TNT, Diamond Ore, Wool...)
- 🎒 Full Inventory (E dabayein)
- 🌞 Day/Night Cycle
- 📱 Mobile + PC dono par chalti hai
- 💾 World Save & Download
- 👤 Login / Signup System

## 🎮 Controls
| Key | Action |
|-----|--------|
| WASD / Arrows | Chalna |
| Space | Jump |
| Left Click | Block Todna |
| Right Click | Block Lagana |
| E | Inventory |
